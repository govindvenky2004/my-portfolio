## 🪄 Overview

This portfolio is designed to reflect my personality as a developer — minimal yet modern, fast yet powerful.  
It serves as my personal space to highlight my projects, skills, and achievements.

✨ **Key Highlights:**
- 🧠 Typing intro animation using <code>react-typed</code>  
- 🎨 Glassmorphism-inspired dark UI  
- 💼 Projects with source links  
- 📫 EmailJS-powered contact form (sends messages directly to my inbox)  
- ⚡ Super fast performance with Vite  
- 📱 Fully responsive for all devices

## 🚀 Getting Started

To run this project locally:

```bash
# 1️⃣ Clone this repository
git clone https://github.com/govindvenky2004/portfolio.git

# 2️⃣ Navigate to the project folder
cd portfolio

# 3️⃣ Install dependencies
npm install

# 4️⃣ Start the development server
npm run dev
