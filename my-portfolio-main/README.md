# Govind Venkatesh — Portfolio

Personal portfolio website built with React.js + Vite.

## Live Site
https://govindvenky2004.github.io/my-portfolio/

## Tech Stack
- React.js, Vite
- CSS (custom, no frameworks)
- EmailJS (contact form)
- GitHub Pages (hosting)

## Sections
- Hero — Introduction with typewriter effect
- About — Background and journey timeline
- Skills — Technologies grouped by category
- Projects — Featured projects with links
- Contact — EmailJS-powered contact form

## Run Locally
git clone https://github.com/govindvenky2004/my-portfolio.git
cd my-portfolio
npm install
npm run dev

## Deploy
npm run build
npm run deploy
